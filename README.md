# UbuntuPay & Kasi Koin Ecosystem

A combined fintech and circular-economy platform for township payments, rewards, and digital entrepreneurship.

## Overview
UbuntuPay powers the digital payment rails and financial flows.
KasiKoin powers the mobile wallet, reward tokens, and community ecosystem.

## Stack
- Web app: Vite + Vanilla JS
- Mobile app: React Native + Expo
- Backend: Node.js + Express + MongoDB
- Security: JWT + bcrypt
- Rewards: Kasi Koin logic + merchant incentives

## Modules
- Wallet management
- Peer-to-peer transfers
- QR pay and receive
- Utility payments
- Kasi Koin rewards
- Merchant settlement
- Community marketplace spending

## Run
1. Install dependencies:
   npm install
2. Start backend:
   npm run dev:server
3. Start web app:
   npm run dev:web
4. Start mobile app:
   npm run dev:mobile
